# Editor de Video

## Cómo instalarlo

1. Descarga **InstalarEditorDeVideo.exe**, nada más. Está abajo, en «Assets» de la versión `current`, o en este enlace directo:
   https://github.com/Kerwin-Core/web-videoeditor-releases/releases/download/current/InstalarEditorDeVideo.exe

   Los otros archivos (`VideoEditor-app.zip`, `manifest.json`, `manifest.sig`, `revocations.json`) los descarga el editor solo. No hace falta bajarlos.

2. Abre el archivo que descargaste. Windows puede mostrar un aviso azul que dice **«Windows protegió su PC»**. Es normal con este programa:
   - haz clic en **«Más información»**,
   - después haz clic en **«Ejecutar de todas formas»**.

3. Sigue los pasos de la ventana: revisa tu PC, te pide la llave de activación y elige dónde guardar tus proyectos. Al final aparece el icono **«Editor de Video»** en el escritorio.

Solo se instala una vez. Después, el editor se actualiza solo cada vez que lo abres con internet.

## Para comprobar que el archivo es el correcto

Si quieres estar seguro de que el archivo no cambió, compara este código con el que te pase quien te dio el editor:

SHA-256 de InstalarEditorDeVideo.exe: abb8281fadcd8608ab13125b06e606ec1f987ffba89b84176c95dae02bdb0e9b

## Si algo no funciona

Avisa a quien te pasó el editor y muéstrale lo que dice la pantalla.
